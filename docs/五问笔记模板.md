# 五问笔记模板（论文精读用）

每读一篇论文，按下面的五个问题写一页 Markdown。放在 `notes/<论文简称>.md`。

---

# [论文标题]

**作者 / 单位**：  
**出处 / 年份 / DOI 或 arXiv**：  
**阅读日期**：  
**我的标签**：精读 / 泛读 / 选读

---

## 1. 要解决什么？

用自己的话写 1 段。要避免抄摘要。回答清三个问题：

- 这个领域里最头疼的问题是什么？
- 这篇工作假设/认为的关键挑战是什么？
- 它解决了哪一类子问题（检测 / 控力 / 适配 / 数据 / 硬件）？

---

---

## 3. 方法核心一句话？

不超过 20 字。用"主语 + 做了什么 + 效果"格式：

例：  
- "用 GRU + 手工频带能量拼接做二分类滑移检测"  
- "用 LLM 自动写奖励函数训练灵巧手策略"  
- "压电+压阻双模态触觉 + QP 内力优化"

---

## 4. 实验哪张表 / 哪段最关键？

**截图或复述这张表的列头和数值**。回答：

- 这张表想证明什么？
- 它相比 SOTA 提升在哪？
- 如果让你做 reviewer，你会怎么评价这张表？

---

## 5. 我能改什么 / 借什么？

写 3-5 条具体想法。每条尽量具体到方法和指标。

例：
- "把它的频带划分换成我的可学习频带 + 它的 QP 力控，做端到端联合训练"
- "用 BioTac 数据集复现它的实验，对比一下泛化性"
- "把它的小样本评估（5 物体训练、5 物体测试）作为我的标准 ablation"

---

## 6. 引用价值判断

- 是否要写进我论文的引言？（选 1-3 句相关话引用）
- 是否要做 baseline 对比？
- 是否要做方法迁移 / 思路借鉴？

---

## 7. 我的盲点（可选）

读完后我还不懂什么？哪里需要补前置知识？

例：
- "不懂 CARM 双路融合，需要回去读 FTFNet 原版"
- "没搞清楚 sim-to-real 的 domain randomization 细节"
